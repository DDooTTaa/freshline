# 이미지 폴더

이 폴더에 앱에서 사용할 이미지 파일들을 저장하세요.

## 사용 방법

1. 이미지 파일을 이 폴더에 추가하세요.
2. 코드에서 다음과 같이 사용할 수 있습니다:

```dart
Image.asset('assets/images/your_image.png')
```

## 권장 이미지 형식

- PNG: 투명 배경이 필요한 경우
- JPG/JPEG: 사진이나 복잡한 이미지
- SVG: 벡터 이미지 (별도 패키지 필요)

## 주의사항

- 이미지 파일명은 영문, 숫자, 언더스코어(_), 하이픈(-)만 사용하세요.
- 공백이나 특수문자는 피하세요.
- 파일 크기를 최적화하여 앱 크기를 줄이세요.
